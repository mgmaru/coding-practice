# 課題: アクセスログ集計CLI `logstat`

## 概要

テキストのアクセスログを読み込み、ステータスコード・パス・IPなどの軸で件数を集計し、ランキング形式で出力するCLIツールを作る。

- 言語: Go
- 制約: 標準ライブラリのみ（外部依存なし）

## 入力フォーマット

スペース区切りの簡易ログ。1行 = 1リクエストで、5フィールド。

```
IP METHOD PATH STATUS BYTES
```

例:

```
192.168.0.1 GET /index.html 200 1024
192.168.0.2 POST /api/login 401 256
```

※ テスト用ログは `sample.log` を使用（不正行を意図的に含む）。

## コマンド仕様

```
logstat <logfile> [--by status|path|ip] [--top N] [--json]
```

| 項目 | 説明 | デフォルト |
| --- | --- | --- |
| `<logfile>` | 集計対象のログファイル | （必須） |
| `--by` | 集計軸（status / path / ip） | status |
| `--top N` | 上位 N 件のみ表示 | 全件 |
| `--json` | JSON 形式で出力 | テキスト（ランキング表） |

## 受け入れ条件（DoD）

- [ ] 引数なし、またはファイルが存在しない場合、わかりやすいエラーを標準エラー出力に出し、終了コード 1 で終わる
- [ ] フィールド数が合わない不正な行はスキップし、件数を警告する（途中で落ちない）
- [ ] `--by status` で件数の降順に集計結果を出力できる
- [ ] `--top 3` で上位 3 件に絞れる
- [ ] `--json` で機械可読な出力ができる
- [ ] 件数が同じ場合の並び順が安定している（キー名で第 2 ソート）

## スコープ

- 150〜200 行程度
- 標準ライブラリのみ、外部依存なし
- 配置: `tools/logstat/`（テスト用ログは `testdata/` に置く）

## 発展（任意）

- 標準入力に対応し、パイプで使えるようにする
- バイト数の合計・平均も集計する
- パース処理を関数として切り出し、テストを 1 本書く

## 設計のポイント（実装前に考えること）

- 集計軸（`--by`）が 3 種類ある。軸が増えても破綻しない構造をどう作るか
- 「不正な行」をどう定義するか（フィールド数の判定基準）。スキップと警告をどう出し分けるか
- 同件数のときの並び順をどう安定させるか
- エラー（ファイルなし等）と警告（不正行）を、出力先・終了コードでどう区別するか
